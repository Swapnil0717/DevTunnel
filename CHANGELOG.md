# Changelog

All notable changes to DevTunnel are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html) for published releases of the CLI (`@devtunnelcli/cli`).

## [Unreleased]

### Changed

- Relicensed from the DevTunnel Source-Available License to the **MIT License**. DevTunnel is now open source.
- Rewrote the README, ARCHITECTURE, ROADMAP, GLOSSARY, CONTRIBUTING, SECURITY and CODE_OF_CONDUCT to describe the project as it is built today, and replaced placeholder contact details with real ones.
- Rewrote the backend, frontend and CLI READMEs, and filled in `devtunnel-backend/CLI_AUTH_SETUP.md`.
- Updated the website FAQ answer on whether DevTunnel is open source.

### Removed

- The Contributor License Agreement (`CLA.md`). Contributions are now accepted under the MIT License with no separate agreement. The "I have signed the CLA" checkbox was removed from the pull request template and from pull requests opened by `dev submit` on DevTunnel tasks, and the CLA message was removed from `dev submit` output.
